# Smart Tracker design references

These six clickable HTML files are sample-data interaction references. The integrated Next.js application lives in `src`; its remaining work and verification limits are listed in `../docs/IMPLEMENTATION_STATUS.md`.

Edit `_source/core.html`, then regenerate all six designs from this repository root:

```sh
node design-reference/_source/build.mjs design-reference
```

Edit `_source/start.html` and copy it to `00 Start Here.html` whenever the index changes. Do not edit generated designs individually. `Implementation Prompt.md` records routes and expected behavior; later dated amendments supersede earlier appearance defaults.
