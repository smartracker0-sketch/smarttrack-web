Design directions

Signature is the chosen direction. The five alternatives share its pages, live map and data, and differ only in navigation and frame. Every file is clickable with sample data, light and dark mode, and search on Ctrl K.

★ Signature · chosen

01 Signature

Deep-blue sidebar with hub panels, a clean top bar, and one live map behind every map page.

  • Sidebar 200 px with an icon rail; hubs open a section panel that starts on Overview
  • Short hub panels with up to seven items; related pages stay in tabs below the title
  • Live map: vehicle list, hover card, Exit focus, tool dock, details / remote control / fuel / trips drawers, nearby vehicles and POIs, full replay
  • Dashboard: fleet motion, fuel snapshot, status pies, driver, telemetry and video bands, fleet km, activity, mileage table; Arrange and Customize
  • Tables: vehicle reg first, KPI filters, bulk bar, import / export, row detail dialog, numbered paging, scrollbars top and bottom

Shared by every design

  • Deep-blue Signature sidebar: #132F86 → #0F2160 → #0A1338; brand #1D4ED8
  • Browser tab shows "Smart Tracker" with the Smart Tracker logo
  • Map pages float their panel over one shared map; the map never reloads between them
  • Dashboard is its own full page, with a colour per category in every pie chart
  • No add shortcut on the map panel; records are added on their own pages
  • Motion status: Moving, Idle, Stopped, Inactive; vehicle rows keep aligned status and age columns
  • Table tabs, segments and page size are remembered per page; Enter opens a focused row
  • Settings have separate sections, validation, and a sticky Save changes / Cancel bar
  • Support below Settings: searchable answers and a request form; contacts come from root-superadmin Platform settings
  • Compact, unboxed headers have page icons and clearly selected tabs; the tenant picker keeps All tenants separate
  • Mileage scrolls inside a short 220px area with no visible scrollbar; AI opens in a compact panel
  • Overview panels show operational follow-ups; Video events include evidence previews
  • Ctrl/⌘+K opens search; Esc closes the top layer; Space toggles replay
